Der Anbieter prüft, kuratiert und hostet diese Inhalte nicht; der Katalog gibt Quelle, Version, Beschreibung und Voraussetzungen so wieder, wie die Autorinnen und Autoren sie angegeben haben. Die Signatur des Katalogs belegt nur, dass der Katalog vom Anbieter stammt, nicht, dass ein Eintrag fehlerfrei, sicher oder rechtmäßig ist.

Ein Plugin läuft als eigener Prozess mit Ihren Benutzerrechten und ohne Sandbox. Es kann Dateien lesen, ändern und löschen, eigene Netzwerkverbindungen aufbauen und weitere Programme starten. Prüfen Sie den Quelltext, bevor Sie ein Plugin installieren, und installieren Sie nur, was Sie verstehen und dessen Autorin oder Autor Sie vertrauen. Die Installation erfolgt auf eigene Verantwortung. Für ein Plugin oder Theme, seine Lizenz und seine Datenverarbeitung ist die Person verantwortlich, die es veröffentlicht hat.

Der Anbieter darf Katalogeinträge sperren, wenn ihm ein Verstoß oder eine Gefahr bekannt wird; eine gesperrte Version wird in smabar deaktiviert, der lokale Code bleibt erhalten. Eine Pflicht zur Prüfung oder Sperrung besteht nicht. Ein Anspruch auf Verfügbarkeit des Katalogs oder einzelner Einträge besteht nicht; der Anbieter kann den Community Store jederzeit ändern oder einstellen.

## 3. Updates

Direktinstallationen (DEB, RPM, Windows-Installer) prüfen regelmäßig, ob eine neuere Version vorliegt, und zeigen sie an. Ein Update wird nur installiert, wenn Sie es auslösen; smabar installiert ausschließlich Pakete, deren Signatur zum in smabar hinterlegten Schlüssel des Anbieters passt. Bei einer Installation aus dem Microsoft Store übernimmt der Store die Aktualisierung. Welche Daten dabei übertragen werden, beschreiben die Datenschutzhinweise der Desktop-App unter https://smabar.com/de/app-privacy/.
